# Poppy protocol proposals

Private review copy of Decagon's SMS verification-code extension proposal for the [Personal Agent Protocol](https://github.com/personal-agent-protocol/personal-agent-protocol).

This repository contains the original versions of the files touched by the proposal on `main`, and the proposed changes on the review branch. It is a focused documentation snapshot, not a full copy of the upstream site or its Git history. The proposal diff is identical to the original public proposal.

Original upstream baseline: `589743afa56ee02bea71d1509c29b0b4ca5b3e50`.
Original proposal: `5420af4fb542b6c124feaab123547344f720630f`.
